# 功能与平台差异

核查日期：2026-11-04。源码基线：宿主 `c768cb12c86e59b60fbc69149013850edce509b0`；本仓首个正式版本为 `1.0.0`（待发布）。生产 Kotlin 源码逐字节迁移；构建独立化并把公开签名所需 `ktor-client-core` 改为 `api`，新增重试合同回归。

## 分层与 API 边界

只有 `http-core`，没有独立 UI、Kuikly Module 或原生分发包。公共包为 `com.dgtang.live.data.remote`。

| 能力 | Android | iOS | OpenHarmony | 宿主与限制 |
| --- | --- | --- | --- | --- |
| `AppHttpClient`、请求/响应、JSON | commonMain | commonMain | commonMain | 注入 URL、身份、隐私、脱敏日志、业务错误映射 |
| `createHttpClient`、`httpTransport` | Ktor + OkHttp | Ktor + Darwin | Ktor + Curl | `HttpClient`/engine/config/request/response 类型作为公开 API，core 依赖传递 |
| 引擎 factory | `createAndroidHttpClientEngine` | `createIosHttpClientEngine`，`waitsForConnectivity=true` | `createOhosHttpClientEngine` | iOS 首次无线授权期间等待系统联网；实际网络/证书由系统决定 |
| 超时与取消 | 共用期限计时 | 相同 | 相同 | 默认 30,000 ms；准备与传输分别计预算。外部取消继续传播 |
| 重试 | 默认 0 | 默认 0 | 默认 0 | 仅调用方显式确认幂等的请求启用；5xx/网络异常/超时，退避 200–800 ms；4xx、取消与响应解析失败不重试 |
| 拦截器与宿主 hook | 共用 | 共用 | 共用 | 请求按声明顺序，结果逆序；固定原请求 context，普通观察异常交由宿主记录，取消不得吞掉 |
| Multipart 字节/流上传 | Ktor 引擎 | Ktor 引擎 | Ktor 引擎 | 宿主持有文件和权限；组件不打开业务路径、不申请媒体权限 |
| 稳定失败原因 | timeout / TLS / 网络等平台异常映射 | NSError 等平台异常映射 | Curl 超时/连接/证书映射 | 未分类返回 null，不伪造业务错误；HTTP 非 2xx 是正常响应 |
| Client 资源 | `close()` 关闭内部 Client | 相同 | 相同 | 宿主在 owner 结束时关闭；取消单请求不等于关闭共享 Client |

不包含业务认证、会话、隐私同意、品牌配置、缓存、设备文件生命周期、H5 Bridge 或页面导航。公共参数与默认值见源码；迁移不新增通用请求框架。
